# Travel Zine Map · 旅行摄影地理视觉

将旅行摄影地理视觉提示词封装成一个可重复调用的 Skill：保留原片，添加透明地图，呈现克制自然的独立杂志风格。

#下载
将https://github.com/candy359/travel-zine-map复制到豆包或者codex让他帮你安装即可

## 使用

在支持 Skill 的客户端中安装此文件夹，提供照片和拍摄地点，然后调用本 Skill。例如在 Codex 中发送：

```text
$travel-zine-map
拍摄地点：福建平潭，具体机位不详。
请按 Skill 中的要求处理这张照片。
```

只需要提示词时，也可以说“请按这个 Skill 输出提示词”。其他客户端按其自己的方式安装或读取 SKILL.md，不保证使用相同调用符号。

## 内容

SKILL.md 保留原始提示词的九项要求：保护原片、真实地理特征、透明地图、负空间布局、15%–25% 的地图占比、细线与低饱和度、小红点大致定位、原始画幅及克制的印刷质感。

本 Skill 只使用当前平台已有能力，不要求安装依赖、下载大批数据或搭建环境；也不强制交付工程文件或制作报告。实际出图取决于平台现有能力，不能满足要求时应说明限制。
