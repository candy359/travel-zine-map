# Travel Zine Map · 旅行摄影地理视觉

保留旅行摄影原片，以真实地理数据制作透明地图图层，合成为克制、自然的 Editorial Photography / Travel Zine 风格作品。

## 这是什么

这是一个供 Codex 豆包  等兼容 Agent Skills 的 AI 环境读取的工作流程 Skill。核心规则在 `SKILL.md`，界面名称与调用提示在 `agents/openai.yaml`。

当前版本不包含独立的出图程序、地图服务、自动安装依赖的脚本或预先打包的地图数据。需要由使用者的 AI 环境调用可用工具执行制作。其他客户端的安装方法和工具兼容性需要分别验证。

## 核心要求

- 保留人物、建筑、山体、天空、原有色彩与光影；不重新生成整张照片。
- 保持原始画幅比例，默认保持正确显示方向的原始像素尺寸。
- 根据地点自动选择真实城市街网、海岸线、水系或有来源的山地地形。
- 独立透明地图层优先放在负空间，不遮挡摄影主体。
- 地图默认约占画面的 15%–25%，主体保护优先于这个比例。
- 以细线、低饱和度颜色、少量英文地名和一个小红点组织视觉。
- 缺少准确 GPS 时仅表示大致区域，并标注 `Approx. location` 或 `Approx. area`。
- 印刷质感只用于新增地图层，不给整张原片加滤镜。

## 使用前需要什么

| 能力 | 用途 | 可用实现举例 |
| --- | --- | --- |
| 读取本地图片与元数据 | 查看构图、尺寸、方向与色彩配置 | 图片查看工具、EXIF 读取工具 |
| 获取地理数据 | 查询和下载可信地图几何，核验地名 | 网络访问、用户提供的 GeoJSON 或其他合法地理素材 |
| 编辑和渲染地图 | 将真实几何绘制成独立透明层 | SVG 工具、矢量渲染器 |
| 图层合成与文件输出 | 合成 PNG，保留原图并导出图层 | Pillow、ImageMagick 或合适的图层编辑器 |

上表列举的是可选实现，并非必须全部安装。仅具备文字聊天能力的环境无法完成全部文件交付。所选 AI 产品、服务和数据源的费用与权限由使用者自行配置，Skill 不附带账号或额度。

## 在 Codex或豆包 中安装

### 方法一：让安装器从仓库安装

把下方整段发给 Codex或豆包：

```text

https://github.com/candy359/travel-zine-map

```

安装器应先检查仓库布局。它可能需要网络访问与本地写入权限。安装完成后发送下一条消息；若仍未显示，可重启 Codex 再检查。

### 方法二：下载 ZIP 后手动安装

1. 在 GitHub 仓库点击 `Code → Download ZIP`，解压文件。
2. 将含有 `SKILL.md` 与 `agents/` 的文件夹命名为 `travel-zine-map`。
3. 将该文件夹放进个人目录下的 `.agents/skills/`，最终文件位置应为 `~/.agents/skills/travel-zine-map/SKILL.md`。
4. 也可仅在一个项目中使用，放进该项目的 `.agents/skills/travel-zine-map/`。
5. 如果已存在同名 Skill，先检查已有版本，避免覆盖自己的修改或造成多个位置重复加载。

Windows 中 `~` 表示当前用户目录，通常形如 `C:\Users\你的用户名`；macOS/Linux 中为当前用户的主目录。不同安装器或版本可能使用自己的目标目录，以实际安装结果为准。

安装与发现规则参考 [OpenAI 官方 Skill 文档](https://learn.chatgpt.com/docs/build-skills)。

## 开始使用

先附上原始照片，或提供 AI 可读取的本地原图路径，再发送：

```text
$travel-zine-map

拍摄地点：福建平潭，具体机位不详。
请将所附旅行照片制作成独立杂志风格的地理视觉作品。
保留原片，不裁切、不调色、不重新生成。
请自动选择合适的地图模式，仅表示大致拍摄区域。
输出合成 PNG、透明地图 PNG 和可编辑地图文件，并附地理数据来源。
```

如果已经有可靠坐标，可提供给 AI；若只有城市或景区名称，直接说明即可。不要为凑齐输入而填写猜测坐标。

## 默认交付

- 保持原画幅的合成 PNG。
- 独立透明地图 PNG。
- 可编辑地图 SVG 或实际使用的图层工程。
- 简短制作记录：数据来源、访问日期、地图范围、位置精度、署名要求与布局信息。

这些是工作流程要求的交付目标。实际执行环境缺少工具或可靠地图数据时，应明确说明缺失条件，不把文字方案当作完成品。

## 常见问题

**下载后为什么没有自动开始制作？**

下载、安装和调用是不同步骤。需要将 Skill 放入客户端可发现的位置，然后附照片与地点发起任务。

**为什么 AI 只给了方案，没有图片？**

检查其是否能读写文件、下载地理数据、渲染透明图层并合成图片。Skill 不能替代这些工具。

**没有 GPS 可以用吗？**

可以。提供可识别的区域，红点仅表示区域级大致位置，不显示伪造的精确坐标。

**能保证每个 AI 客户端得到相同结果吗？**

不能。具体模型、工具、数据和输入会影响结果，应检查原片完整性、地理真实性和地图可读性。
